# Codex AutoResume v0.2.0

- Native Linux and macOS desktop apps, with the same queue, session journal and scheduling safeguards as Windows.
- Linux x64/ARM64, macOS Intel/Apple Silicon, and Windows x64 downloads. Each includes .NET and a matching continuity diagnostic.
- Desktop shortcuts are created by default during npm installation and the first normal launch. Use the Desktop shortcut button or `codexautoresume shortcut` to repair one.
- Native Codex discovery handles Unix npm installations without executing shell wrappers.

Desktop must stay closed while AutoResume owns the selected sessions. Existing UUIDs require the continuity check on the machine containing their history. Backend execution does not guarantee Desktop UI synchronization.

macOS apps are ad-hoc signed, not notarized. macOS may require reviewing the app in Privacy & Security before opening it. Linux needs an X11 desktop or XWayland; some desktops require Allow Launching for a new `.desktop` shortcut.
