# Codex AutoResume v0.3.0

Codex Desktop can stay open while AutoResume connects and finds your chats.

- Automatic native CLI detection and read-only connection on launch.
- An empty queue fills with up to five existing chats: verified active first, then most recent backend activity.
- Existing priorities, prompts and attempt journals stay intact. Scheduling starts OFF.
- Unknown Desktop activity is labeled honestly. No replacement chats or continuation messages are sent during discovery.
- Explicit execution handoff revalidates each UUID before scheduling. Completed work stays disarmed; uncertain attempts are never blindly retried.
- Read-only refresh survives list failures, preserves workspace identity and clears stale activity indicators.

Windows x64, Linux x64/ARM64 and macOS Intel/Apple Silicon downloads include .NET. Desktop must still be closed for exclusive execution ownership. Concurrent Desktop execution and Desktop UI synchronization remain unsupported. macOS apps are ad-hoc signed, not notarized. The SuckerPunch pink remains a labeled preview placeholder.
