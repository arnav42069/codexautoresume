# Codex AutoResume v0.2.2

A compact Phosphor dashboard for Windows, automatic Codex executable discovery, and Linux/macOS builds. Desktop shortcuts are created by default.

- Configurable accent presets, native color picker, readable text, saved appearance, reduced motion/glow and Windows accessibility preferences.
- Verified connection health, visible failure details, live queue statuses and expandable event history.
- Native CLI validation through saved paths, PATH and npm installations; no manual vendor path is needed for normal setup.
- WPF theme binding and rendered-color assertions prevent the light-background issue found in v0.2.0. UI error reporting now reads presentation snapshots safely alongside scheduler events.

The SuckerPunch pink is a clearly named preview placeholder; the original brand color is still needed. Existing UUIDs, exclusive ownership, rate-limit permissions and duplicate-message safeguards stay intact. Desktop UI synchronization is unsupported.

Downloads include .NET: Windows x64, Linux x64/ARM64 and macOS Intel/Apple Silicon. macOS builds are ad-hoc signed, not notarized.
