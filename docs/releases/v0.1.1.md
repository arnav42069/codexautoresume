# Codex AutoResume v0.1.1

Codex CLI detection now handles npm installations automatically, including the
Windows package layout where `codex.exe` is nested beneath `@openai/codex`.
You no longer need terminal commands to find that executable.

- Find Codex searches again; Browse lets you choose a custom executable.
- Connection errors explain the next step in the app.
- Downloads show progress and stop when the connection stalls.

Desktop must remain closed while AutoResume owns the selected sessions. Original
Desktop UUIDs still need the continuity check. Backend execution does not guarantee
Desktop UI synchronization.
