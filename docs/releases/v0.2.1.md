# Codex AutoResume v0.2.1

The Phosphor Windows dashboard now applies its dark background and readable text to the main window. This corrects a WPF style lookup issue found while reviewing native screenshots. The UI check now asserts those colors before a release can publish.

Includes automatic native Codex discovery, configurable accents, saved appearance settings, default desktop shortcuts and the Linux/macOS builds introduced in v0.2.0. The original SuckerPunch brand color is still needed; the pink preset is clearly marked as a preview placeholder.

Windows x64, Linux x64/ARM64 and macOS Intel/Apple Silicon downloads include .NET. Existing UUIDs, exclusive ownership and duplicate-message safeguards are unchanged. Desktop UI synchronization remains unsupported. macOS builds are ad-hoc signed and are not notarized.
