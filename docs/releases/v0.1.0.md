First Windows x64 release of Codex AutoResume.

Download `CodexAutoResume-win-x64.zip`, extract it, and run `CodexAutoResume.exe`. The .NET runtime is included. You still need the native Codex CLI and Git for Windows.

- Queue up to five existing sessions, with priorities and optional parallel runs.
- Track live status, elapsed time and usage reset estimates.
- Keep completed work disarmed and review uncertain attempts before retrying.

The release workflow runs all 55 automated tests and checks Windows UI startup before publishing.

**Existing Desktop conversation compatibility remains unverified.** Use the companion `CodexAutoResume-DesktopProbe-win-x64.zip` to check your original UUIDs first. Keep Desktop closed during handoff and execution. Backend continuity does not guarantee Desktop UI updates. No replacement conversations are created.

`SHA256SUMS.txt` contains the ZIP checksums.
